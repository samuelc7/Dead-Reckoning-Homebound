# Dead Reckoning: Homebound

## Tech Stack

- C++20
- SDL3
- OpenGL 3.3 Core
- GLAD
- GLM
- stb_image

## Building

**1. Clone the repo with submodules:**
```
git clone --recurse-submodules https://github.com/samuelc7/Dead-Reckoning-Homebound.git
```

**2. Open in Visual Studio:**
- File -> Open -> CMake...
- Select `CMakeLists.txt` in the project root

**3. Build**
- Set the startup item to `DeadReckoningHomebound.exe`
- Build -> Build All (`Ctrl+Shift+B`)

**4. Run:**
- Debug -> Start (`Ctrl+F5`)
